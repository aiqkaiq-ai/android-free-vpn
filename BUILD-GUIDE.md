# Build Standalone Windows EXE Setup\n\n## Quick Build (3 Steps)\n\n### Option 1: Automatic Build (Recommended)\n\n```bash\n# Windows Command Prompt or PowerShell\nnpm install\nnpm run build:all\n```\n\nThis creates:\n- `dist/bot.exe` - Standalone bot (no Node.js needed)\n- `dist/MudrexCryptoBotSetup.exe` - Windows installer\n\n### Option 2: Manual Build\n\n```bash\n# Step 1: Install dependencies\nnpm install\n\n# Step 2: Build EXE\nnpm run build:exe\n\n# Step 3: Create Installer (requires Inno Setup)\nnpm run build:installer\n```\n\n---\n\n## System Requirements\n\n### To Build:\n- Windows 10/11\n- Node.js 18+ (https://nodejs.org/)\n- NPM (comes with Node.js)\n- **Optional:** Inno Setup (for installer only)\n\n### To Run:\n- Windows 10/11 Pro\n- No Node.js required!\n- ~50 MB free space\n- Internet connection\n\n---\n\n## Installation Guide\n\n### 1. Install Node.js (If Not Already Installed)\n\n1. Visit https://nodejs.org/\n2. Download \"LTS\" version\n3. Run installer, click \"Next\" multiple times\n4. Restart computer\n\n### 2. Clone or Download Repository\n\n```bash\ngit clone https://github.com/aiqkaiq-ai/android-free-vpn.git\ncd android-free-vpn\ngit checkout crypto-trading-bot\n```\n\n### 3. Build the EXE\n\n```bash\n# Install dependencies\nnpm install\n\n# Create standalone EXE\nnpm run build:exe\n```\n\nYou'll see:\n```\n📝 Compiling TypeScript...\n📦 Creating standalone EXE...\n✅ Created: dist/bot.exe\n```\n\n### 4. (Optional) Create Windows Installer\n\n**Option A: Using Inno Setup (Pro)**\n\n1. Download Inno Setup: https://jrsoftware.org/isdl.php\n2. Install it\n3. Run:\n   ```bash\n   npm run build:installer\n   ```\n4. Get `MudrexCryptoBotSetup.exe` in `dist/` folder\n\n**Option B: Without Inno Setup**\n\nJust use the `bot.exe` directly and create a folder:\n\n```bash\nmkdir \"Program Files\\MudrexCryptoBot\"\ncopy dist\\bot.exe \"Program Files\\MudrexCryptoBot\\\"\ncopy .env.template \"Program Files\\MudrexCryptoBot\\\"\n```\n\n---\n\n## Output Files\n\nAfter building, you'll have:\n\n```\nandroid-free-vpn/\n├── dist/\n│   ├── bot.exe                      ← Standalone executable\n│   ├── MudrexCryptoBotSetup.exe    ← Windows installer (if built)\n│   └── (compiled JS files)\n├── src/                             (TypeScript source)\n├── build/\n│   ├── setup.iss                    (Inno Setup script)\n│   └── build-windows.bat            (build script)\n└── package.json\n```\n\n---\n\n## Distribution\n\n### Share `bot.exe` Directly\n\n1. Copy `dist/bot.exe` to a folder\n2. Create `.env.template` file in same folder\n3. Zip the folder\n4. Share with users\n\n**Users do:**\n1. Extract zip\n2. Rename `.env.template` to `.env`\n3. Add their API keys\n4. Double-click `bot.exe`\n\n### Share Windows Installer\n\nJust share `MudrexCryptoBotSetup.exe`\n- Users double-click it\n- Auto-installs to Program Files\n- Creates Start Menu entry\n- Creates Desktop shortcut\n\n---\n\n## Build Troubleshooting\n\n### \"npm: command not found\"\n- Node.js not installed\n- Download from https://nodejs.org/\n- Restart computer after installing\n- Verify: `node --version`\n\n### \"Cannot find module 'axios'\"\n```bash\nnpm install\n```\n\n### Build fails with TypeScript errors\n```bash\n# Clean and rebuild\nrm -r dist node_modules\nnpm install\nnpm run build\n```\n\n### EXE file too large\nThis is normal (Node.js + code = ~50MB)\n- `--compress` flag reduces size 30%\n- Already enabled in package.json\n\n### Antivirus blocks .exe\n- Some antivirus software flags new executables\n- This is normal for any new EXE\n- You can:\n  - Add to antivirus whitelist\n  - Or build your own copy (source code is open)\n\n---\n\n## Advanced: Custom Build\n\n### Change bot name/version\n\nEdit `setup.iss`:\n```ini\n[Setup]\nAppName=My Trading Bot\nAppVersion=2.0.0\n```\n\n### Change default directory\n\n```ini\nDefaultDirName={autopf}\\MyBotFolder\n```\n\n### Add more files to installer\n\n```ini\n[Files]\nSource: \"my-custom-file.txt\"; DestDir: \"{app}\"\n```\n\n### Change icon\n\nAdd a `.ico` file to `build/` folder:\n```ini\n[Setup]\nAppIcon=build\\myicon.ico\n```\n\n---\n\n## Automated Builds with GitHub Actions\n\nCreate `.github/workflows/build.yml`:\n\n```yaml\nname: Build Windows EXE\n\non:\n  push:\n    branches: [main]\n\njobs:\n  build:\n    runs-on: windows-latest\n    steps:\n      - uses: actions/checkout@v2\n      - uses: actions/setup-node@v2\n        with:\n          node-version: '18'\n      - run: npm install\n      - run: npm run build:exe\n      - uses: actions/upload-artifact@v2\n        with:\n          name: bot.exe\n          path: dist/bot.exe\n```\n\nNow every push auto-builds the EXE!
